ML Architecture

SecurePass uses a Random Forest Classifier trained on 3,600 synthetic passwords. Here's exactly how it works.

1 Pipeline

⌨️ Raw Password Plain text string
⚙️ Feature Extraction 7 numeric features
🌲 Random Forest 100 decision trees
🏷️ Prediction Weak / Medium / Strong

2 Feature Engineering

The raw string is converted into a 7-dimensional numeric vector. The model never sees the original characters.

Feature Description
lengthTotal number of characters
has_upperContains at least one uppercase letter (A–Z)
has_lowerContains at least one lowercase letter (a–z)
has_digitContains at least one digit (0–9)
has_symbolContains at least one non-alphanumeric character
entropyShannon entropy — measures unpredictability
unique_ratioRatio of unique characters to total length
